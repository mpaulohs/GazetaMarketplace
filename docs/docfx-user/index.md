# Welcome to NET10 Project Example

Get started with our application in minutes!

## What is NET10 Project Example?

NET10 Project Example is a modern .NET 10 demonstration project showcasing full-stack architecture with:

- **ASP.NET Core MVC** - Traditional web application with Razor views
- **Minimal API** - RESTful API endpoints with OpenAPI/Swagger
- **End-to-End Testing** - Playwright browser automation
- **Centralized Package Management** - Simplified dependency management

This example project demonstrates best practices for building robust, testable .NET applications.
